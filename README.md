# M5Stack Tab5 VNC Client

M5Stack Tab5用のVNCクライアント実装です。ArduinoVNCライブラリを使用して、Tab5をVNCビューワーとして動作させます。

## 概要

このプロジェクトは、M5Stack Tab5デバイスをVNC（Virtual Network Computing）クライアントとして使用するためのPlatformIO環境を提供します。Tab5の5インチタッチスクリーンディスプレイを活用し、リモートデスクトップの表示とタッチ操作による入力が可能です。

## ハードウェア要件

| 項目 | 仕様 |
|------|------|
| デバイス | M5Stack Tab5 |
| メインMCU | ESP32-P4 (RISC-V Dual-core 400MHz) |
| ワイヤレス | ESP32-C6 (Wi-Fi 6) |
| ディスプレイ | 5インチ IPS TFT 1280×720 (MIPI-DSI) |
| タッチ | GT911 マルチタッチコントローラ |
| メモリ | 16MB Flash, 32MB PSRAM |

## セットアップ手順

### 1. PlatformIOのインストール

VS Codeを使用している場合は、PlatformIO IDE拡張機能をインストールしてください。

### 2. プロジェクトのクローン

```bash
git clone <repository-url>
cd m5stack_tab5_vnc
```

### 3. 接続設定について

Wi-FiとVNCの設定は、書込み後にTab5本体の画面で登録します。`src/main.cpp`の編集や`user_setting.h`の作成は不要です。最大8件の接続プロファイルを内部NVSへ保存でき、microSDも不要です。

既存の`user_setting.h`に`WIFI_SSID`、`WIFI_PASSWORD`、`VNC_HOST`、`VNC_PORT`、`VNC_PASSWORD`が定義されている場合は、NVSが未初期化のときだけ「Imported settings」として取り込みます。長すぎる値や無効な設定は切り捨てず、取り込みを中止するため、本体で登録してください。特にVNCパスワードは従来のVNC認証の上限である8バイト以内です。

一度初期化した後は、ファームウェアの更新や最後のプロファイルの削除によって古い設定を再取り込みしません。フラッシュ全消去やNVSを消去する操作では、本体に保存した設定も失われます。通常のアプリ書込みでも、パーティション構成を変える場合は注意してください。

### 4. ビルドとアップロード

```bash
# ビルド
pio run

# アップロード
pio run --target upload

# シリアルモニター
pio device monitor
```

## 使用方法

1. 電源を入れると接続プロファイルの選択画面が表示されます。
2. 初回は「New」で設定を登録します。登録済みの場合は使うプロファイルをタッチして選びます。
3. 「Connect」を押すと、選択したWi-FiとVNCサーバーへ順番に接続します。
4. 接続成功後、VNCデスクトップをタッチで操作できます。

プロファイルが1件だけでも自動接続せず、選択画面で操作を待ちます。前回VNC接続に成功したプロファイルが初期選択されます。Wi-Fi接続中は「Choose profile」で取り消せます。Wi-Fi接続に失敗した場合は「Retry」で再試行するか、「Choose profile」で選び直し・編集できます。

### 接続プロファイルの編集

起動時の選択画面で「New」は追加、「Edit」は選択中の設定を編集、「Delete」は確認後に削除します。名前、SSID、Wi-Fiパスワード、VNCホスト、ポート、VNCパスワードを登録します。Wi-FiとVNCは一組の設定なので、同じWi-Fi上の別PCも別プロファイルにできます。

文字入力は本体のソフトキーボードで行います。英数字と一般的な記号に対応し、日本語入力・変換には対応していません。CardKBが接続されている場合は入力欄で利用できます。設定画面のキーやタッチはVNCへ送信されません。パスワードは通常マスク表示され、シリアルログには出力しません。

ソフトキーボードでは「Done」で入力欄へ反映し、「Cancel」でその欄の変更を取り消します。設定編集画面の「Save」でNVSへ保存します。編集をキャンセルした場合は保存済みの値を変更しません。

SSIDは最大32バイトです。Wi-Fiパスワードは空欄ならオープンネットワーク、設定する場合は8〜63バイトまたは64桁の16進数です。VNCパスワードはASCIIで最大8バイトで、認証なしのサーバーでは空欄にできます。VNCポートは1〜65535で、初期値は5900です。企業向けWi-Fi認証などは対象外です。

VNC接続開始後の接続先変更・設定編集は、電源を入れ直して起動時の選択画面で行ってください。再起動なしの接続先切替は行いません。VNC接続失敗時も既存の再試行動作となるため、設定を直す場合は再起動してください。

NVS保存は、それだけで認証情報を暗号化するものではありません。第三者に本体を渡す場合などは、物理アクセスによる読取りを考慮してください。保存破損や容量不足のときは通知し、NVS全体を自動消去しません。

破損や未知の保存形式のスロットは「Damaged slot」と表示し、自動で上書きしません。該当スロットを選び「Delete」で確認後に削除すると、そのスロットを新規登録に使えるようになります。

### タッチ操作

| 操作 | 動作 |
|------|------|
| 1本指タップ | マウス左クリック |
| 1本指ドラッグ | マウスドラッグ |
| 2本指ドラッグ（上下） | マウスホイールスクロール |
| 3本指タッチ | 全画面再描画（画面乱れ修復） |
| 画面上端からスワイプダウン | 接続情報画面を表示 |

### 接続情報画面

画面上端から下にスワイプすると、接続情報画面が表示されます。

**表示内容：**
- 選択した接続プロファイル名
- WiFiネットワーク名（SSID）
- VNCサーバーのIPアドレス
- VNCポート番号
- WiFi接続状態
- VNC接続状態

**VNC画面に戻る方法：**
- 3本指でタッチ

### ボタン操作

| ボタン | 動作 |
|--------|------|
| 電源ボタン | 再接続を試行 |

### 画面が乱れた場合

VNC画面の描画が乱れた場合は、**3本指でタッチ**すると全画面再描画が実行され、正常な表示に戻ります。

### 保存・入力検証のテスト

実機なしでも、Linuxなどで`g++`を使ってNVSモックによるテストを実行できます。

```bash
bash tests/run_profile_tests.sh
SANITIZE=1 bash tests/run_profile_tests.sh
bash tests/run_profile_ui_tests.sh
```

保存・入力検証は12グループ、画面入力はタッチとCardKBのモックで8シナリオを確認します。後者には明示Connect、編集取消し、指の解放・ドラッグ・複数指による誤操作防止、既存UTF-8値の保持、ポート範囲、破損設定の明示削除を含みます。メモリ検査はASan/UBSanを使用します。

これらはPC上のモックテストです。実際のNVS、Wi-Fi、VNC、本体フォント・画面・タッチの動作は実機で確認してください。

### 今回の実機確認

まず2件のプロファイルを登録し、電源を入れ直しても設定が残ること、選択前は接続せず「Connect」で選んだ接続先へ進むことを確認してください。続いて、Wi-Fiパスワードを誤った設定で「Retry」「Choose profile」を試し、設定を編集して接続できることを確認します。

設定画面ではソフトキーボードの記号、パスワードのShow/Hide、CardKB入力、欄のCancelと編集全体のCancelを確認してください。VNC接続後は従来のクリック・ドラッグ、2本指スクロール、上端スワイプでの情報表示、3本指での復帰・再描画が維持されているか確認してください。

## トラブルシューティング

### Wi-Fi接続に失敗する場合

1. SSIDとパスワードが正しいか確認してください
2. Tab5がWi-Fiルーターの範囲内にあることを確認してください
3. 2.4GHz帯のWi-Fiを使用していることを確認してください

### VNC接続に失敗する場合

1. VNCサーバーが起動していることを確認してください
2. VNCサーバーのIPアドレスとポートが正しいか確認してください
3. VNCパスワードが正しいか確認してください
4. ファイアウォールがVNCポート（通常5900）をブロックしていないか確認してください

### 画面表示が遅い場合

VNCサーバー側で以下の設定を試してください。

1. 色深度を16ビットに下げる
2. 圧縮レベルを上げる
3. 解像度を下げる

## 技術的な注意事項

### ESP32-P4について

M5Stack Tab5はESP32-P4をメインMCUとして使用しています。ESP32-P4はRISC-Vアーキテクチャを採用しており、従来のESP32（Xtensa）とは異なります。このプロジェクトでは、pioarduinoプラットフォームを使用してESP32-P4のArduinoサポートを実現しています。

### Wi-Fi接続について

Tab5ではESP32-C6がWi-Fiモジュールとして動作します。M5Unifiedライブラリがこの構成を抽象化しているため、通常のWiFiライブラリと同様に使用できます。
